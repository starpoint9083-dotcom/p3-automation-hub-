# AI 원장실

뮤엠영어 + 노피곰 학원/공부방 원장을 위한 AI 운영 시스템.

## Product goal
원장이 데이터를 읽는 사람이 아니라, AI가 먼저 판단하고 원장이 결정만 하게 한다.

## V1 scope
1. 학생별 성장카드
2. 월간 성장보고서 자동 생성
3. 퇴원 위험 예측
4. 신규상담 사전 문진 + 후속관리
5. 오늘의 원장실 브리핑
6. AI 모집실장

## Killer loop
학생을 데려온다 -> 만족시킨다 -> 안 나가게 한다 -> 빈자리를 다시 채운다.

## Marketing KPI
조회수가 아니라 상담 예약과 신규 등록.

## Safety
- 기존 P1/P2/P3 운영 리소스는 수정하지 않는다.
- 기존 교육 콘텐츠를 대체하지 않고 운영 AI 층만 제공한다.
- 학생/학부모 개인정보는 최소 수집, 목적 제한, 권한 분리, 삭제 가능성을 기본으로 한다.
- AI 판단은 원장의 의사결정 보조이며 자동 확정/발송은 명시적 규칙과 승인 하에서만 수행한다.
